### 2. 更新检查（新文件 `fungal_annot/core/updater.py`）

沿用 gb_fetcher 惯例（领域异常 + 重试退避 + 校验响应形状）：

- `UpdateCheckError(Exception)`
- `RELEASE_API = "https://api.github.com/repos/yananzh/MycoFACT/releases/latest"`
- `parse_version("v0.2.1") -> (0,2,1)`（去 `v` 前缀、逐段整数比较）、`is_newer(latest, current)`
- `fetch_latest_release(timeout=8, retries=2)`：**stdlib `urllib.request` + `json`**（requests 不在 requirements，不新增依赖）；显式 User-Agent `MycoFACT/<version>`（GitHub API 必需）；校验 `tag_name`/`html_url`；失败退避重试，异常统一转 `UpdateCheckError`
- `check_for_update(current, ...) -> dict | None`：None = 已最新；dict = `{version, url, name, published_at, notes}`

### 3. UI 流程（about.py 内）

- `CheckUpdatesRunnable(QRunnable)` + `done/failed` 信号，在 QThreadPool 跑（沿用 worker.py 的防 GC 引用惯例）
- `run_update_check(parent)` 供菜单和 About 按钮共用：
  - 检查中：按钮禁用 + "Checking for updates…" 内联提示
  - 已最新：内联提示 "You're up to date (Version 0.1.0)."
  - 有新版本：弹出 `UpdateAvailableDialog`——"Version X.Y.Z is available (you have A.B.C)" + release notes 摘录（前 ~12 行）+ **[Download from GitHub]**（PrimaryButton，`QDesktopServices.openUrl` 打开 release 页，复用 page_export.py:179 惯例）
  - 失败：`QMessageBox.warning` 简短提示
- 菜单栏 Guide 与 About 之间插入 "Check Updates"（`main_window.py:147-156`）
